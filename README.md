# Task Manager

## 📌 Descrição
O **Task Manager** é um projeto em C++ desenvolvido para simular a gestão de tarefas e processos.  
Ele permite gerenciar atividades de forma simples via linha de comando, ajudando a organizar e controlar o fluxo de execução.

---

## 🚀 Funcionalidades
- Criar, listar e remover tarefas.
- Marcar tarefas como concluídas.
- Interface de linha de comando simples e intuitiva.
- Estrutura modular em C++.

---

## 🛠 Pré-requisitos
Antes de começar, certifique-se de ter instalado em sua máquina:

- Compilador **C++11** ou superior (g++, clang++, MSVC, etc).
- **Make** (opcional, caso queira usar o Makefile).

---

## ⚙️ Como compilar e executar

### Usando o Makefile:
```bash
make
./task-manager
